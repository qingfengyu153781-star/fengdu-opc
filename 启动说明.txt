欢迎试用「枫独 · OPC 经营助手」Demo
=====================================

这是一个可直接运行的 Gradio 网页应用，无需配置 API key 即可体验全部功能。核心是「联网搜索当地政策 + 规则判定资格」：联网搜索当地政策需网络，断网/受限时自动降级本地通用政策库（保底，不白屏）。

一、开始运行（推荐先看这条）

方式 A：双击启动（推荐，无需敲命令）
  1. 确保电脑已安装 Python 3.9+（未装则去 https://www.python.org/downloads/ 下载，
     安装时务必勾选 "Add Python to PATH"）
  2. 双击本文件夹里的「启动.bat」
  3. 它会自动安装依赖 → 自动打开浏览器 → 服务启动
  4. 使用完关闭黑色窗口即停止

方式 B：命令行运行
  1. 打开终端（cmd / PowerShell）
  2. 进入本文件夹：  cd /d "解压后的本文件夹路径"
  3. 安装依赖（首次需联网）：  pip install -r requirements.txt
  4. 启动：  python app.py
  5. 浏览器打开 http://localhost:7860 即可使用

方式 C：在线体验（无需安装）
  魔搭创空间在线版：https://modelscope.cn/studios/qingfengyuqing/fengdu

二、可以体验什么

  ① 补贴材料预审  一句话描述经营情况，AI 主动追问，匹配政策、预审材料清单
  ② 经营健康诊断  填经营数据，生成健康度/政策机会/风险三指数驾驶舱
  ③ 经营合规问答  问税务/合同/开票/社保问题，带来源解答；可让 AI 推荐该问的问题
  ④ 政策导入      粘贴任意地区真实政策原文，自动结构化入库
  ⑤ 政策动态·对比 实时搜索任意地区最新政策（可自定义关键词）→ 一键入库；对比两地区能申什么

三、推荐演示路径（约 2 分钟）

  1. 在「补贴材料预审」输入：
     我是温州的个体户摄影师，开了 2 年，月入 3 万，主要靠一个大客户
  2. 看 AI 主动追问补齐信息 → 生成材料清单 + 政策机会 + 风险
  3. 切到「经营健康诊断」填经营数据 → 看驾驶舱三指数
  4. 切到「经营合规问答」问：小规模纳税人月销售额多少免征增值税
  5. 切到「政策动态·对比」地区填"杭州"点搜索 → 看 OPC 新政官方来源 → 一键入库 → 对比温州/杭州

四、注意事项

  - 核心 = 联网搜索当地政策（需网络）+ 规则判定资格；断网/受限时自动降级本地通用政策库，保证不白屏（保底能力，非核心卖点）
  - 配置环境变量 MODELSCOPE_API_KEY 后，可获得 AI 语义理解 / 精准搜索词 / 合规问答深度增强
  - 所有政策输出标注「以官方最新文件为准」，辅助参考，不替代专业机构判断

祝评审顺利！
