# 🍁 枫独 · OPC 经营助手

**GOAI 世界人工智能开源大赛 · 无界应用｜BoundlessAgents · AI+金融 赛道**

面向一人公司（OPC = One Person Company）的经营辅助 Agent。让一个没有任何财务/法务背景的普通人，也能像有专属顾问一样把公司开明白。

> 产品开发者本人就是目标用户（正在亲身经历：搜政策、填补贴申请、算成本）——这是"创始人=用户"的真实产品，不是猜出来的场景。

---

## 功能（三个场景）

| 场景 | 说明 | 核心能力 |
|------|------|---------|
| **① 补贴材料预审** | 一句话描述经营情况 → AI 主动追问 → 匹配政策 → 生成材料清单 + 缺项指引 + 资格风险 | 多轮追问 · 规则匹配 · 材料预审 |
| **② 经营健康诊断** | 填经营数据 → 6 维状态向量 → 三指数（健康/政策机会/风险）→ 驾驶舱可视化 + 行动建议 | 经营状态模型 · 指数计算 |
| **③ 经营合规问答** | 税务/合同/开票/社保问题 → 带来源的合规解答 | 知识库 + LLM（可选） |
| **④ 政策导入** | 粘贴某地真实政策原文 → AI 结构化 → 入库该地区 → 地区下拉即可切换 | 多地区扩展 · 政策更新 |

**多地区支持**：地区下拉可切换（温州/杭州/…）。国家级通用政策（小微/增值税减免/研发加计）任何地区自动叠加；地区政策跟随切换。其他城市政策可通过「政策导入」粘贴真实原文入库。

## 快速开始

### 本地运行

```bash
pip install -r requirements.txt
python app.py
```

打开 http://localhost:7860

> 无需任何 API key 即可运行（核心闭环为规则引擎驱动）。可选配置以获得 AI 深度回答：
> ```bash
> # Windows
> set MODELSCOPE_API_KEY=ms-xxx
> # Linux / Mac
> export MODELSCOPE_API_KEY=ms-xxx
> ```

### 部署到魔搭创空间（在线体验）

1. 在魔搭创空间新建应用，镜像选择 `python`，**Gradio 版本选 6.x**（与代码兼容）
2. 上传本目录全部文件（含 `assets/`）
3. 环境变量：`MODELSCOPE_API_KEY`（可选）
4. 部署后提交在线链接

## 技术架构

**规则引擎 + LLM 混合**（不是纯聊天机器人）：

```
用户描述
  → [多轮追问状态机] 缺哪些字段 → 逐项问清（主动询问，不依赖一次说清）
  → [规则引擎] 政策资格匹配（确定性）→ 材料清单 → 缺项/格式检测
  → [经营状态模型] 6 维状态向量 → 三指数（健康/政策机会/风险）
  → [驾驶舱 UI] 实时可视化 + 来源引用 + 风险提示
```

| 层 | 技术 | 说明 |
|----|------|------|
| 政策匹配 | 规则引擎（纯 Python） | 资格条件逐条判定（match/no/unknown），100% 可复现 |
| 经营诊断 | 状态模型 | 6 维向量 X → 健康 H / 政策 P / 风险 R（透明可解释，5 维等权 20%） |
| 多轮追问 | 状态机 + 关键词抽取 | 确定性，无需 LLM 也能跑 |
| LLM（可选） | Qwen3 系（魔搭免费 API） | 合规问答 / 政策导入结构化 / 追问润色，带 fallback 链 |
| 驾驶舱 | Gradio 6.x + HTML | 枫叶主题 UI，左对话右驾驶舱 |

**政策机会定义**：驾驶舱「政策机会」只统计**地区差异化政策**（需要用户主动申请的那部分），国家级通用政策（小型微利/增值税/六税两费）列为"自动享受"单独展示——因为全国人人都有，不算差异化机会。摄影师示例实测输出 **健康72 / 政策机会3 / 风险中**，与 PPT P6/P7 一致。

**零白屏保证**：核心闭环（预审/诊断/风险）纯规则引擎，不依赖 API。LLM 仅用于可选增强，无 key 时自动降级 mock → Demo 永不白屏。

## 多地区扩展指南

**方法一：政策导入（推荐）**
1. 打开 Demo「④ 政策导入」页
2. 填目标地区名 + 粘贴真实政策原文 → 入库
3. 重启服务 → 地区下拉出现新地区

**方法二：手工模板**
1. 复制 `policies/region_template.py` → `policies/<code>.py`
2. 用真实政策数据替换 POLICIES（**不要编造**）
3. 在 `policies/__init__.py` 的 `REGIONS` 注册

> ⚠️ 数据诚实原则：只收录真实政策。杭州库当前标注「示例数据·待补充」，不填充编造内容。

## 数据来源与合规

- **政策数据来源**：公开政策文件（温州 OPC 创业扶持申请操作指南、财政部/税务总局公告等），全部带 `source` + `source_url` 可溯源
- **评分模型**：公开的产品定义（5 维等权 20%），每个维度带打分理由，非黑盒
- **行业边界**：所有输出标注"辅助参考，不替代专业机构/金融机构最终判断"；不给确定性投资/信贷/赔付结论
- **用户数据**：不收集真实个人信息，Demo 使用模拟数据（摄影师案例为示例）
