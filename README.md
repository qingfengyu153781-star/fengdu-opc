# 🍁 枫独 · OPC 经营助手

> ⚖️ **评委请查阅**：**`FOR_JUDGES_PROJECT_SUMMARY.md`（项目一页纸）** —— 目标用户/核心问题/核心流程/安全合规边界速览。



**GOAI 世界人工智能开源大赛 · 无界应用｜BoundlessAgents · AI+金融 赛道**

面向一人公司（OPC = One Person Company）的经营辅助 Agent。让一个没有任何财务/法务背景的普通人，也能像有专属顾问一样把公司开明白。

> 产品开发者本人就是目标用户（正在亲身经历：搜政策、填补贴申请、算成本）——这是"创始人=用户"的真实产品，不是猜出来的场景。

## 功能（五个场景）

| 场景 | 说明 | 核心能力 |
|------|------|---------|
| **① 补贴材料预审** | 一句话描述经营情况 → AI 主动追问 → 匹配政策 → 生成材料清单 + 缺项指引 + 资格风险 | 多轮追问 · 规则匹配 · 材料预审 |
| **② 经营健康诊断** | 填经营数据 → 6 维状态向量 → 三指数（健康/政策机会/风险）→ 驾驶舱可视化 + 行动建议 | 经营状态模型 · 指数计算 |
| **③ 经营合规问答** | 税务/合同/开票/社保问题 → 带来源的合规解答；可让 AI 推荐该问的问题 | 知识库 + LLM（可选）+ 联网搜索 |
| **④ 政策导入** | 粘贴某地真实政策原文 → AI 结构化 → 入库该地区 → 顶部地区框填该地区即可用 | 多地区扩展 · 政策更新 |
| **⑤ 政策动态 · 地区对比** | 实时搜索任意地区最新政策（**搜索词三档**：输入指定关键词 / 描述需求 AI 提炼 / 自动 OPC 热点词）→ 一键入库；同画像对比两地区能申什么 | 实时搜索 · 零预置 · 一键入库 · 地区对比 |

**多地区支持**：顶部「经营地区」输入任意城市/省份（如：温州 / 杭州 / 重庆）回车即切换。国家级通用政策（小微/增值税减免/研发加计）任何地区自动叠加；地区政策跟随切换；未收录地区自动实时搜索当地政策。其他城市政策可通过「政策导入」粘贴真实原文入库。

## 技术架构

**联网搜索匹配 + LLM 理解**（不是纯聊天机器人）：

```
用户描述
  → [多轮追问状态机] 缺哪些字段 → 逐项问清（主动询问）
  → [联网搜索] 搜当地政策（Bing/DDG/百度 多源，可配 Bing API）→ 资格匹配（规则）
  → [LLM] 语义理解字段 / 生成精准搜索词 / 合规问答
  → [经营状态模型] 6 维状态向量 → 三指数（健康/政策机会/风险）
  → [驾驶舱 UI] 实时可视化 + 来源引用 + 风险提示
```

| 层 | 技术 | 说明 |
|----|------|------|
| 政策获取 | **联网搜索**（核心） | Bing/DDG/百度 多源爬虫 + 官方来源优先；可配 `BING_SEARCH_API_KEY`/`SEARXNG_URL` 更稳 |
| 政策匹配 | 规则引擎（纯 Python） | 资格条件逐条判定（match/no/unknown），带来源可溯源 |
| 语义理解 | **LLM**（Qwen3 系） | 理解任意行业/地区、生成精准搜索词、合规问答、政策导入结构化 |
| 经营诊断 | 状态模型 | 6 维向量 X → 健康 H / 政策 P / 风险 R（透明可解释，5 维等权 20%） |
| 驾驶舱 | Gradio 6.x + HTML | 枫叶主题 UI，左对话右驾驶舱 |

**政策机会定义**：驾驶舱「政策机会」只统计**地区差异化政策**（需要用户主动申请的那部分），国家级通用政策（小型微利/增值税/六税两费）列为"自动享受"单独展示——因为全国人人都有，不算差异化机会。摄影师示例实测输出 **健康72 / 政策机会3 / 风险中**，与 PPT P6/P7 一致。

**断网保底**：联网搜索是核心（需网络）；断网/搜索失败时自动降级本地通用政策库 + 规则引擎 → 不白屏、不造假（这是保命兜底，不是核心卖点）。

## 多地区扩展指南

**方法一：政策动态实时搜索（零预置，推荐）**
1. 打开 Demo「⑤ 政策动态 · 地区对比」页
2. 输入地区（如 杭州）→ 可输入指定关键词（如 工位注册 / Token券）或描述需求让 AI 提炼，或留空自动搜索
3. 搜到的政策带官方来源 → 点「✅ 一键入库」人工确认后写入本地库（免重启，本次会话即可用）

**方法二：政策导入（粘贴原文）**
1. 打开 Demo「④ 政策导入」页
2. 填目标地区名 + 粘贴真实政策原文 → 入库
3. 免重启（热加载）：入库后顶部地区输入框自动填入库地区，本次会话即可切换

**方法二：手工模板**
1. 复制 `policies/region_template.py` → `policies/<code>.py`
2. 用真实政策数据替换 POLICIES（**不要编造**）
3. 在 `policies/__init__.py` 的 `REGIONS` 注册

> ⚠️ 数据诚实原则：只收录真实政策。杭州库当前无预收录政策——切换「杭州」自动实时搜索当地政策 + 通用方向兜底，不填充编造内容。

## 数据来源与合规

- **政策数据来源**：公开政策文件（温州 OPC 创业扶持申请操作指南、财政部/税务总局公告等），全部带 `source` + `source_url` 可溯源
- **评分模型**：公开的产品定义（5 维等权 20%），每个维度带打分理由，非黑盒
- **行业边界**：所有输出标注"辅助参考，不替代专业机构/金融机构最终判断"；不给确定性投资/信贷/赔付结论
- **用户数据**：不收集真实个人信息，Demo 使用模拟数据（摄影师案例为示例）
